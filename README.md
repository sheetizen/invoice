# Invoice Generator by Sheetizen 🧾

Aplikasi web sederhana berbasis HTML, CSS (Tailwind CSS), dan JavaScript untuk membuat, mengedit, dan mengelola invoice secara mudah.

## 🌐 DEMO

Coba langsung aplikasinya di sini: **[inv.sheetizen.web.id](https://inv.sheetizen.web.id/)**

## ✨ Fitur Utama

* **Edit Langsung:** Ubah detail invoice (nomor, tanggal, nama klien, alamat, kontak) langsung di halaman.
* **Manajemen Item:** Tambah, hapus, dan edit item invoice (deskripsi, harga, kuantitas).
* **Perhitungan Otomatis:** Subtotal, diskon, total, DP, dan sisa tagihan dihitung secara otomatis.
* **Input Logo:** Masukkan URL logo perusahaan Anda untuk ditampilkan di invoice.
* **Informasi Pembayaran:** Tambahkan detail rekening bank atau metode pembayaran lainnya.
* **Cetak / Simpan PDF:** Hasilkan tampilan siap cetak atau simpan sebagai PDF melalui fungsi print browser.
* **Kirim via WhatsApp:** Buat pesan WhatsApp otomatis berisi ringkasan invoice untuk dikirim ke klien.
* **Judul Tab Dinamis:** Judul tab browser otomatis berubah sesuai nama klien yang dimasukkan.
* **Desain Responsif:** Tampilan menyesuaikan dengan berbagai ukuran layar.

## 🖥️ Cara Menggunakan (Lokal - PC/Laptop)

1.  Unduh file `index.html`.
2.  Buka file `index.html` tersebut menggunakan browser web Anda (Chrome, Firefox, Edge, dll.).
3.  Aplikasi siap digunakan.

**Catatan:** 🌐 Saat menjalankan secara lokal, Anda **memerlukan koneksi internet** agar gaya (styling) dari Tailwind CSS dapat dimuat dengan benar dari CDN.

## 📱 Cara Menggunakan (Lokal - Android)

1.  Unduh file `index.html` dan simpan di penyimpanan ponsel Anda (misal, folder Download).
2.  Buka aplikasi **File Manager** 📁 di ponsel Anda.
3.  Cari dan ketuk file `index.html`.
4.  Pilih untuk membukanya dengan **browser web** (Chrome, Firefox, dll.).
5.  Aplikasi siap digunakan.

**Catatan:** 🌐 Sama seperti di PC, Anda **memerlukan koneksi internet** agar gaya (styling) dari Tailwind CSS dapat dimuat dengan benar.

## ☁️ Cara Deploy (Online)

Aplikasi ini adalah website statis murni dan dapat di-deploy dengan mudah ke berbagai platform hosting gratis untuk situs statis:

1.  **Simpan File:** Pastikan Anda memiliki file `index.html` yang final.
2.  **Pilih Platform:**
    * [Netlify](https://www.netlify.com/)
    * [Vercel](https://vercel.com/)
    * [GitHub Pages](https://pages.github.com/)
    * [Cloudflare Pages](https://pages.cloudflare.com/)
3.  **Unggah/Deploy:** Ikuti petunjuk platform pilihan Anda. Biasanya cukup dengan *drag-and-drop* file `index.html` atau menghubungkan repositori Git Anda.
4.  **Akses:** Platform akan memberikan URL publik agar aplikasi Anda bisa diakses oleh siapa saja.
